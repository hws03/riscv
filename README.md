# RISC-V (32-bit) Processor 

32-bit RISC-V, single-cycle and pipelined, in SystemVerilog. 

FPGA (Vivado/Artix-7) + ASIC (LibreLane/SKY130) flows.


<img width="450" height="1214" alt="pipeline-block-diagram" src="https://github.com/user-attachments/assets/262880fb-3153-4a97-855f-fb98bb01d433" />




## Repo layout
`single-cycle` and `pipelined` each contain: 
- `rtl/`
- `tb/`
- `programs/` (.asm, .txt and .mem)
- `fpga/` (README, constraints and reports/results)
- `asic/` (README, config and results).
